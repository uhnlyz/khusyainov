# Практическая работа № 3

Тема: архитектура программного обеспечения и применение паттернов проектирования в проекте «Персональный тайм-трекер на Java».

## Материалы в репозитории

- `Отчёт_по_практической_работе_3.md` — текстовая копия отчёта: обоснование архитектуры, выбор паттернов, конкретные классы Java, система сборки Maven, структура каталогов, команды сборки и ограничения промежуточной версии.
- `diagrams/architecture.dot` — исходник диаграммы слоистой архитектуры.
- `diagrams/patterns.dot` — исходник схемы взаимодействия паттернов.

Оформленные PDF- и DOCX-версии отчёта передаются отдельными файлами вместе с комплектом практических работ. В репозитории оставлены текстовый вариант и исходники диаграмм, чтобы их можно было просматривать и развивать без потери исходного содержимого.
