# Практическая работа № 3 — персональный тайм-трекер

## Итоговый материал для сдачи

Основной файл — **`Техническое_описание_тайм-трекера_ПР2-ПР3.pdf`**. Это единый документ: принятая спецификация требований ПР2, дополненная новой главой по архитектуре, паттернам проектирования и системе сборки Maven. Исходный протокол интервью сохранён в приложении.

В едином документе также учтены замечания преподавателя:

- Windows не фиксируется как единственная целевая ОС; поддержка Windows, Linux и macOS проверяется отдельно;
- на Use Case Diagram актор соединён с каждым прецедентом отдельной ассоциацией, без общей линии-разветвителя.

`Глава_ПР3_к_техническому_описанию.docx` — редактируемый исходник новой главы. `Глава_ПР3_к_техническому_описанию.pdf` — отдельный экспорт главы для просмотра; при сдаче предпочтителен единый PDF.

## Диаграммы

Все исходники `.drawio` открываются и редактируются в [diagrams.net](https://app.diagrams.net/):

- `diagrams/use-case-corrected.drawio` — исправленная диаграмма вариантов использования;
- `diagrams/architecture.drawio` — слоистая архитектура приложения;
- `diagrams/patterns-overview.drawio` — обзор пяти выбранных паттернов;
- `diagrams/patterns.drawio` — подробная схема паттернов из предыдущей версии.

PNG-файлы в каталоге — экспорты схем, использованные в документации. DOT-файлы оставлены как дополнительные текстовые исходники.

## Java-проект и сборка

Исходный Maven-проект находится в `../../personal-time-tracker/`.

Требования: JDK 17 или новее, Apache Maven 3.9 или новее. Сборка и обычный запуск:

```bash
cd personal-time-tracker
mvn clean package
java -jar target/personal-time-tracker.jar
```

Диагностический режим проверяет запуск JAR, SQLite, таймер, стратегии и экспорт CSV/PDF без открытия GUI:

```bash
java -jar target/personal-time-tracker.jar --self-check
```

GitHub Actions выполняет сборку и самопроверку на Ubuntu, Windows и macOS. Это подтверждает переносимость сборки и базовых интеграций; графический интерфейс и системный трей дополнительно проверяются в соответствующей настольной среде.

## Границы текущей версии

Это промежуточная версия для демонстрации архитектуры и сборки по ПР3. Полная аналитика, фильтры и история отчётов, восстановление незавершённых сеансов и расширенные настройки остаются дальнейшими этапами разработки. JUnit 5 подключён как тестовая зависимость для ПР4; полноценный набор тестов будет оформляться в следующей практической работе.
