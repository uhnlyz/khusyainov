# Проектные материалы — персональный тайм-трекер

Репозиторий содержит учебные материалы и исходный код проекта «Персональный тайм-трекер на Java» для дисциплины «Проектирование и архитектура программного обеспечения».

## Состав

- `KR1/` — материалы первой практической работы (исходные файлы сохранены без изменений).
- `docs/practice-2/` — отчёт по практической работе № 2 (исходный PDF и текстовая копия SRS для поиска по содержимому).
- `docs/practice-3/` — отчёт по практической работе № 3 в DOCX и PDF, диаграммы архитектуры и паттернов; схемы `architecture.drawio` и `patterns.drawio` редактируются в diagrams.net.
- `personal-time-tracker/` — Maven-проект на Java 17 с разделением на пакеты, SQLite JDBC, Swing/AWT, примерами паттернов проектирования и конфигурацией исполняемого JAR.

## Быстрый запуск приложения

```bash
cd personal-time-tracker
mvn clean package
java -jar target/personal-time-tracker.jar
```

Подробные инструкции и ограничения текущей промежуточной версии приведены в `personal-time-tracker/README.md` и отчёте по практической работе № 3. GitHub Actions дополнительно проверяет сборку на Ubuntu, Windows и macOS с JDK 17.
