# Проектные материалы — персональный тайм-трекер

Репозиторий содержит учебные материалы и исходный код проекта «Персональный тайм-трекер на Java» по дисциплине «Проектирование и архитектура программного обеспечения».

## Состав репозитория

- `KR1/` — исходные файлы первой практической работы; сохранены без изменений.
- `docs/practice-2/` — текстовая копия спецификации требований SRS из практической работы № 2, предназначенная для просмотра и поиска по содержимому GitHub.
- `docs/practice-3/` — текстовый отчёт по практической работе № 3 и исходники архитектурных диаграмм (`.dot`, `.drawio`).
- `personal-time-tracker/` — Maven-проект на Java 17: доменная модель, прикладные сервисы, SQLite-репозитории, Swing/AWT-представление и примеры паттернов проектирования.

Оформленные PDF/DOCX-версии отчётов передаются отдельными файлами вместе с комплектом практических работ. В репозитории хранятся текстовые копии и исходные материалы, удобные для просмотра и версионирования.

## Сборка и запуск

Требуются JDK 17 или новее и Maven 3.9+.

```bash
cd personal-time-tracker
mvn clean package
java -jar target/personal-time-tracker.jar
```

Подробные инструкции и ограничения текущей промежуточной версии приведены в `personal-time-tracker/README.md`.
