# Проектные материалы — персональный тайм-трекер

Репозиторий содержит учебные материалы и исходный код проекта «Персональный тайм-трекер на Java» по дисциплине «Проектирование и архитектура программного обеспечения».

## Состав репозитория

- `KR1/` — исходные файлы первой практической работы; сохранены без изменений.
- `docs/practice-2/` — итоговый PDF-отчёт по практической работе № 2 и текстовая копия SRS для поиска по содержимому GitHub.
- `docs/practice-3/` — итоговые PDF- и DOCX-версии отчёта по практической работе № 3, текстовая копия и редактируемые исходники диаграмм.
- `personal-time-tracker/` — Maven-проект на Java 17: доменная модель, прикладные сервисы, SQLite-репозитории, Swing/AWT-представление и примеры паттернов проектирования.

## Сборка и запуск

Требуются JDK 17 или новее и Maven 3.9+.

```bash
cd personal-time-tracker
mvn clean package
java -jar target/personal-time-tracker.jar
```

Подробные инструкции, зависимости и ограничения промежуточной версии приведены в `personal-time-tracker/README.md`.
