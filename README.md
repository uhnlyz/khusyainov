# Проектные материалы — персональный тайм-трекер

Репозиторий содержит материалы практических работ и исходный код проекта «Персональный тайм-трекер на Java» по дисциплине «Проектирование и архитектура программного обеспечения».

## Структура репозитория

- `KR1/` — первая практическая работа; исходные файлы сохранены без изменений.
- `docs/practice-2/` — принятая спецификация требований (SRS) ПР2 и её текстовая копия.
- `docs/practice-3/` — единый итоговый PDF ПР2+ПР3, редактируемая глава ПР3 и исходники диаграмм draw.io.
- `personal-time-tracker/` — Maven-проект на Java 17 с логическим разделением по пакетам, SQLite JDBC, Swing/AWT, паттернами проектирования и исполняемым JAR.
- `.github/workflows/maven-build.yml` — автоматическая сборка и самопроверка на Ubuntu, Windows и macOS; последний запуск прошёл успешно: https://github.com/uhnlyz/khusyainov/actions/runs/43330929355.

## Итоговый документ ПР2 + ПР3

Для сдачи используй `docs/practice-3/Техническое_описание_тайм-трекера_ПР2-ПР3.pdf`. В нём сохранены материалы ПР2 и интервью, добавлена глава ПР3, исправлена Use Case Diagram и уточнена платформенная независимость.

## Быстрый запуск

```bash
cd personal-time-tracker
mvn clean package
java -jar target/personal-time-tracker.jar
```

Для проверки собранного JAR без открытия графического интерфейса:

```bash
java -jar target/personal-time-tracker.jar --self-check
```

Подробные инструкции и границы промежуточной реализации приведены в `personal-time-tracker/README.md` и `docs/practice-3/README.md`.
